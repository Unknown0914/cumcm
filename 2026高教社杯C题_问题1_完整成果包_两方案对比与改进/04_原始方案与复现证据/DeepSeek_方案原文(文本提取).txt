问题1 详细解答
1. 问题分析
问题1要求：在每天电价和小区负载相同、光伏发电功率预测已知的条件下，制定微网每天
0:00的计划购电策略。要求：
1. 微网提供的电能不低于小区负载；
2. 储能设备在0:00和24:00的储电量相同；
3. 以购电费用最小为目标；
4. 给出指定时间段的购电量、充放电量及全天购电量和购电费。
该问题是一个典型的单日线性规划问题。决策变量为每个时段的购电功率、充电功率、放电
功率和储能电量。目标函数为全天购电费用最小。约束条件包括功率平衡、储能动态、储能
容量、充放电功率限制以及初末储电量相等。
2. 模型假设
1. 附件1给出的电价、小区负载和光伏发电预测功率在当天0:00已知，且全天不变；
2. 储能设备充放电效率均为90%，且充放电过程不随温度、老化等因素变化；
3. 忽略微网内部线路损耗；
4. 购电和售电均通过外部电网完成，不考虑微网向外部电网售电；
5. 储能设备在同一时段内不会同时充电和放电；
6. 时间间隔为10分钟，全天共144个时段；
7. 光伏发电优先供负载使用，剩余电量可给储能充电，不足部分由外网购电或储能放电
补充。

4. 数据预处理
附件1给出从00:10到0:00+1的144个时间点，时间间隔10分钟。将时间点依次编号为
t=1,2,…,144，其中：
t=1 对应00:10；
t=144 对应0:00+1，即24:00；
E0表示0:00的储电量，E144表示24:00的储电量。
全天购电量：
Qtotal = Σt=1144 Ptbuy · Δt
全天购电费：
Ftotal = Σt=1144 ct · Ptbuy · Δt

5.3 约束条件
（1）功率平衡约束
每个时段微网供电必须满足小区负载：
Ptbuy + PVt + Ptdis = Loadt + Ptch,   t=1,…,144
（2）储能动态约束
考虑充放电效率，储能电量递推关系为：
Et = Et-1 + ηc Ptch Δt − (Ptdis / ηd) Δt,   t=1,…,144
其中 ηc=ηd=0.9，Δt=1/6 h。
（3）储能容量约束
Emin ≤ Et ≤ Emax,   t=1,…,144
即：1200 ≤ Et ≤ 10800。
（4）充放电功率约束
0 ≤ Ptch ≤ Pmax,   0 ≤ Ptdis ≤ Pmax,   t=1,…,144
其中 Pmax=5000 kW。
（5）购电功率约束
Ptbuy ≥ 0,   t=1,…,144
（6）初末储电量约束
E0 = 6000,   E144 = E0 = 6000
（7）充放电互斥约束（可选）

6. 模型求解
6.1 求解方法
上述模型为线性规划（LP）模型。变量约 4×144=576 个，约束约 5×144=720 个，规模较
小，可采用以下工具求解：
Python：scipy.optimize.linprog、cvxpy、pulp
MATLAB：linprog
Excel：规划求解
6.2 求解步骤
1. 读取附件1中的电价 ct、负载 Loadt、光伏预测 PVt；
2. 构造线性规划标准形式；
3. 调用求解器求解；
4. 提取 Ptbuy、Ptch、Ptdis、Et；
5. 计算指定时间段购电量、充放电量、全天购电量和购电费；
6. 将结果写入 result1.xlsx。

# ========== 2. 构造线性规划 ==========
# 决策变量顺序: P_buy(n), P_ch(n), P_dis(n), E(n)
# 总变量数 4*n
obj = np.zeros(4*n)
obj[:n] = c * dt    # 目标：购电费用最小
A_eq = []
b_eq = []
# 2.1 功率平衡: P_buy + PV + P_dis = Load + P_ch
for t in range(n):
    row = np.zeros(4*n)
    row[t] = 1            # P_buy
    row[n+t] = -1         # -P_ch
    row[2*n+t] = 1        # P_dis
    A_eq.append(row)
    b_eq.append(Load[t] - PV[t])
# 2.2 储能动态: E_t - E_{t-1} - eta*P_ch*dt + P_dis*dt/eta = 0
for t in range(n):
    row = np.zeros(4*n)
    row[3*n+t] = 1        # E_t
    if t > 0:
        row[3*n+t-1] = -1 # -E_{t-1}
    row[n+t] = -eta * dt          # -eta*P_ch*dt
    row[2*n+t] = dt / eta         # +P_dis*dt/eta
    A_eq.append(row)
    if t == 0:
        b_eq.append(E0)   # E_0 = 6000
    else:
        b_eq.append(0)
# 2.3 末储电量 E_{n-1} = 6000
row = np.zeros(4*n)
row[3*n+n-1] = 1
A_eq.append(row)
b_eq.append(6000)

b_ub = []

    row = np.zeros(4*n)
    row[2*n+t] = 1
    A_ub.append(row); b_ub.append(Pmax)

# 2.5 储能容量上下限
for t in range(n):
    row = np.zeros(4*n)
    row[3*n+t] = 1
    A_ub.append(row); b_ub.append(Emax)

    A_ub.append(row); b_ub.append(-Emin)

res = linprog(obj, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
